## Throughput — `llama-bench`, full offload (`-ngl 99`)

Vulkan backend, `-r 3` (baseline first row is default `-r 5`). Higher is better.

| KV cache | flash-attn | pp512 (t/s) | tg128 (t/s) |
|---|---|---|---|
| f16 | auto | **1028.8 ± 1.2** | **95.3 ± 1.1** |
| f16 | on | 1029.4 ± 3.6 | 96.8 ± 0.1 |
| q8_0 | on | 997.8 ± 0.9 | 93.4 ± 0.2 |
| q4_0 | on | 994.1 ± 0.7 | 92.4 ± 0.1 |

**Read:** prompt processing ~1000 t/s, decode ~92–97 t/s for a 4B Q4_K_M. Flash-attention is
neutral at this size. KV quantization costs **~3–4% decode** (`f16` → `q4_0`).

## VRAM — adapter dedicated usage (includes ~1.1 GB desktop baseline)

Measured with `llama-server` (`-np 1`, `-fa on`, `-ngl 99`), GPU counter
`\GPU Adapter Memory(*)\Dedicated Usage`.

| Config | Adapter VRAM (MB) | Δ over idle |
|---|---|---|
| idle (desktop/driver) | 1134 | — |
| ctx 8192, KV q8_0 | 4226 | ~3092 |
| ctx 32768, KV q8_0 | 6096 | ~4962 |
| ctx 32768, KV q4_0 | 4930 | ~3796 |

**Read:** a 4B Q4 model at **32K context uses only ~6.1 GB** of 12 GB even with q8_0 KV — huge
headroom. Dropping KV to **q4_0 saves ~1.17 GB** at 32K. This confirms a 7–8B Q4 model is comfortable
at moderate context.

Server-reported buffers (verbose load log):

| Config | Vulkan0 model buf | CPU_Mapped model buf | Vulkan0 compute buf |
|---|---|---|---|
| ctx 8192 | 2375.91 MiB | 304.28 MiB | 85.09 MiB |
| ctx 32768 | 2375.91 MiB | 304.28 MiB | 109.09 MiB |

## Observations

- ✅ **Vulkan "just works"** on `gfx1031` with only the graphics driver — no ROCm, no
  `HSA_OVERRIDE_GFX_VERSION`.
- ✅ The card reports its true **12 GB** over Vulkan (12272 MiB).
- **`b16`/bf16 is unsupported** (`bf16: 0`) and there are **no matrix cores** — expected for RDNA 2.
- This build defaults the server to **port `9931`**.
- The 4B tier is far from the VRAM limit; the next interesting test is a **7–8B Q4** model.

## Reproduce

```powershell
$dir = "C:\Users\6700XT\llm\bin\llama-b11541-vulkan"
$model = "C:\Users\6700XT\llm\models\Qwen3-4B-Instruct-2507-Q4_K_M.gguf"

# throughput matrix
& "$dir\llama-bench.exe" -m $model -ngl 99
& "$dir\llama-bench.exe" -m $model -ngl 99 -fa on -ctk q8_0 -ctv q8_0

# serve (observe the launch)
& "$dir\llama-server.exe" -m $model -c 32768 -np 1 -ngl 99 -fa on `
  -ctk q8_0 -ctv q8_0 --host 127.0.0.1 --port 9931
```
