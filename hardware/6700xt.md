# AMD Radeon RX 6700 XT — the card

**Platform:** desktop, bare metal
**Verified:** 2026-10-10 (specs) · `📄 Documented`

## Specs

| Property | Value |
|---|---|
| Architecture | RDNA 2 (Navi 22) |
| GPU codename / ISA | `gfx1031` (also written GFX10.3) |
| Compute units | 40 |
| Stream processors | 2560 |
| Wavefront size | **Wave32** (not Wave64) |
| VRAM | **12 GB GDDR6**, 192-bit |
| Infinity Cache | 96 MB |
| Memory bandwidth | ~384 GB/s |
| PCIe | 4.0 ×16 |
| TBP | ~230 W |
| Released | March 2021 |
| Compute API | **No CUDA.** HIP / ROCm, Vulkan, OpenCL, DirectML |
| Windows driver family | Adrenalin (this machine: `32.0.21045.5002`) |

> **Windows VRAM reporting gotcha:** `Win32_VideoController.AdapterRAM` reports `4 GB` on this card
> because the field is a signed 32-bit value that wraps. Actual VRAM is 12 GB. Use
> `Get-CimInstance Win32_VideoController | Select Name, DriverVersion` and read the driver's own
> overlay, or `dxdiag`, not `AdapterRAM`. `Verified: 2026-10-10`

## Why this card is awkward

- It is **RDNA 2**, which AMD left **outside official ROCm/HIP support on Windows**, even though
  RDNA 3 (7000) and RDNA 4 (9000) are supported. See
  [`../stack/rocm-windows.md`](../stack/rocm-windows.md). `[S1]`
- No CUDA means the enormous CUDA-native training/library ecosystem is unavailable; you live in the
  HIP/Vulkan/OpenCL world.
- It is nevertheless **very capable** for local inference: 12 GB holds a 7–8B model at Q4 comfortably,
  and small 3–4B models run fast. See [`../models/what-fits-12gb.md`](../models/what-fits-12gb.md).

## Identifying it on any OS

```powershell
# Windows
Get-CimInstance Win32_VideoController |
  Where-Object Name -match 'Radeon' |
  Select-Object Name, DriverVersion, AdapterRAM
```

```bash
# Linux
rocminfo | grep -E 'gfx|Name'   # if ROCm installed
lspci | grep -i vga
```

The identifier you will grep for in logs and issue threads everywhere is **`gfx1031`**.
